superseded/, not committed). packaging/debs keeps 1.1.0-2.
packaging/build-110-system-debs.sh DCVER is 1.1.0-3. That script still
packs with dpkg-deb; the payload and control of that pack match this
deb, and the archive hash does not. This file's hash is the
dpkg-buildpackage deb.

NoDisplay overrides in /usr/local/share/applications, the same mechanism
as the XFCE dialogs Command Center already replaced. includes.chroot
copies are identical. The packages are not removed. Each override is the
desktop id from Debian Trixie, which Devuan excalibur ships at the same
version. The file in /usr/local/share wins over /usr/share and is left
alone when the owning package is upgraded.
