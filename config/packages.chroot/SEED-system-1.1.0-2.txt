  matching *_ratio (confirmed: ratios read back 0). Background is set first.

  still installs it). /etc/init.d/procps is Default-Start S and runs
  `sysctl -q --system`, which loads /etc/sysctl.d then /usr/lib/sysctl.d (same
  basename in /etc wins). Its postinst runs update-rc.d, and a dpkg trigger on
  /usr/lib/sysctl.d reapplies sysctl on upgrade outside a chroot. No extra init
  script. lcos-base postinst also applies this file on configure, skipped in a
  chroot and when /etc/sysctl.d/60-lcos-dirty-writeback.conf exists.
